技术围城

September 7, 2026

我老想找些自由度高的游戏来玩，比如 Minecraft，但找来找去，就是找不到合适的。Minecraft 还在更新，可微软现在端出来的东西，在我这样的老玩家眼里就是敷衍。我们这一代老玩家也长大了，热情耗得差不多了，打开游戏，玩不下去；关掉，又不甘心。我在 Steam 上翻来翻去，没一个能填上这个窟窿。

我到底在找什么？我想自由地创作，亲手搭出点东西。那股劲还在，却找不到地方使。或许，是我对技术最原始的热情又醒了。或许，我该做一个自己的开源项目。别再是什么分布式系统、数据库、Agent 插件了。就做一个我自己感兴趣的东西，不依靠 Coding Agent，自己把它做出来。

我曾经想过自己做游戏。六年前，因为疫情居家，开始长时间接触电脑，那时候刚学 Python。我照着书里已经过时的 Pygame API，一边百度，一边翻 CSDN，做过一个很简陋的飞机大战。

同一个暑假，我用三百多行 Python 加上 EasyGUI，写了一个简陋得要命的笔记系统，定位有点像 Obsidian，实际上难用得很。不知道什么时候该封装函数，那干脆不封装。全程 if-else，重复代码铺满屏幕。我还用 Tkinter 帮老师做过一个随机点名器，服役了一年；又写过一个丑得不行的、类似 GeoGebra 的东西，不能平移，不能缩放，只能画一次函数和二次函数的图像，连线都画不连续。

上高中前，抓着最后那点自由的时间，我花了一周做了个带杰哥、阿伟 cosplay 音效的井字棋，Bug 连连。高中暑假忙里偷闲，买来一个二手树莓派和一些小外设，尝试用 Python 还原 Phigros。我甚至想参与 Phigros 的社区复刻项目 Phira 的开发，却发现，我对软件设计一无所知，不知道什么 Git 版本控制，协作流程，甚至连个 GitHub 账号都没有。

那些作品里，只有井字棋留下过可执行文件。后来，那个 32GB 的 U 盘坏了，它和前面几个项目的代码一起，都成了不可溯源之物了。

那时候做的东西，拿今天的眼光看，没几个像样的。可我真的很快乐。

上一次有这样的热情，是在将近两年前。大一上学期，我凭着记忆，翻着那本 2020 年买来的破烂 Python 书，在 CSDN 上硬搜，对着笨重的 Visual Studio，用八百行 Python 做了一个三阶魔方模拟器。没用 AI——那时我没有科学上网手段，也不会用 AI。

借助 Pygame、Tkinter 和 kociemba，它能变色，能打乱，能计时，有键位，能自动复原，能生成当前状态解法。八百行全塞在一个文件里，坐标全靠硬编码，屎山一座。但它真的跑起来了。那是我一点一点写出来的，它真的能转，真的能还原。

我拿着这东西去参加学校的程序设计比赛，到了答辩现场才发现，我看漏了文件，这设计主题是 AI。真他妈荒唐。可至少，做它的时候，我没为了任何人。我就是觉得好玩。

后来做 C 语言课设，一个学生管理系统，没有数据库，没有网络，也没有前后端。我偏要认真做。回调函数、函数指针解耦、三层架构分离，连文件格式都自己设计，当时觉得自己写得高端大气。无 AI 添加纯手搓。

洋洋洒洒两千多行，却 0人在意我写了什么。

他们只在意任务做完没有。你怎么设计，为什么这么设计，花了多少心思，没人在乎。旁边有人用了 AI 辅助，东西照样做得粗制滥造，最后分数跟我一样。我就是觉得不合理。我认真做的那些东西，在这套评分里，就一点区别都没有吗？

这次我是在为别人写代码。我把热情交了出去，等着有人看见，却没人看见。这是我第一次热情受到打击。

如今，会实现 Raft 了，会做软件设计了，懂系统和网络怎么运作了，会用 Linux 了。然后呢？我没有多快乐。技术越学越多，能让我兴奋的东西却越来越少。项目做了一个又一个，最后全成了简历上的几行字，求职时的谈资，下一步的跳板。我能讲清它们用了什么技术、解决了什么问题，却说不出自己到底有多想做它们。

所有权属于我，却不属于我的精神世界。它们可以证明我能干活，可我看着它们，找不到自己。

再看看周围，AI 大狂欢，Vibe Coding，许多人疯狂地往外倒屎代码。我不反对 Vibe Coding。我自己当年写的也是屎山，没什么资格拿代码质量装清高。但你的想法呢？这里面到底有多少东西，是你自己想做的？

你可以不懂软件，不懂工程细节，把你的想法、设计、原型交给 AI 实现。可你不能连自己想要什么都不知道，就等着它替你决定。设计是它给的，细节是它定的，漏洞也是它埋的，最后你接过来：这是我的作品。

你的东西到底在哪？连想法都让出去了，还剩什么？这不只是懒得思考。连原本属于你自己的思想，都快被挤没了。

我想找回那份热情，真的想。与技术深度无关，与手段无关。我就想亲手设计一个东西，知道它为什么长这样，为什么这样运转，哪怕做得稀烂，也是我自己的决定。孩子手里的积木，为什么非得让机器人替他放？连这一块积木都不让我自己搭，搭得再漂亮，我又能有多快乐？

可我不知道该怎么办。以前连函数都不会封装，想做什么就敢做。现在懂了这么多，却连自己想做什么都找不到了。我像是终于翻过了技术这座围城的城墙，回头才发现，创作的快乐被我留在了外面。这城墙，正是这张录取通知书。外面的我想提升技术，里面的我想自由创作。我的灵魂，我活生生的人，被从中间劈开了。一边是做得稀烂却快乐的我，一边是越来越像样、却越来越空的我。但是这其中一半，却对另一半的感受越来越模糊了呢。

我要找回我的精神世界，找回另一半真实的我。我可以不完美，但我想做一个完整的人。
